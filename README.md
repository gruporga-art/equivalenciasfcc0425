# 📚 Portal de Equivalencias LCC — Plan 2004 ↔ Plan 2025

Aplicación web de consulta de equivalencias entre el Plan de Estudios 2004 y el Plan 2025 de la **Licenciatura en Ciencias de la Comunicación** de la **Universidad Veracruzana**, Facultad de Ciencias y Técnicas de la Comunicación diseñado para los Tutorados del docente Dr. Alfredo Reyes GUtierrez.

## 🌐 Acceso en línea

👉 **[Abrir el portal](https://gruporga-art.github.io/equivalencias-lcc/)**

## ✨ Funcionalidades

- ✅ Consulta bidireccional: Plan 2004 → 2025 y Plan 2025 → 2004
- 🔍 Búsqueda con autocompletado por nombre de materia
- 📋 Información de créditos, área académica y observaciones
- ⚠️ Alertas cuando hay diferencias de créditos o cambios de área
- 🔸 Identificación de materias sin equivalencia directa (transferencia AFEL)
- 📱 Diseño responsivo con colores institucionales UV (#18529D / #28AD56)

## 📊 Datos

- **70+ experiencias educativas** catalogadas
- Plan 2004: **391 créditos** totales
- Plan 2025: **380 créditos** totales

## ⚠️ Aviso importante

Este portal es una herramienta de consulta orientativa. La **equivalencia oficial definitiva** la emite la **Coordinación de Control Escolar** de la facultad.

## 🛠️ Tecnología

HTML5 + CSS3 + JavaScript vanilla (sin frameworks, sin backend). Funciona abriendo el archivo `index.html` o mediante GitHub Pages.
